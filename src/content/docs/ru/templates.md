# Шаблоны и подписи

Письма, приказы и договоры обычно составляются один раз в виде шаблона, а затем заполняются для каждого адресата. Для этого в nuvra есть **переменные шаблона** и готовые **блоки подписи**.

## Переменные шаблона

Передайте переменные, которые может использовать шаблон, в пропс `variables`. На панели инструментов появится меню **{ }** для их вставки, а если набрать `{{name}}` с именем известной переменной, этот текст тоже превратится в переменную.

```vue
<script setup lang="ts">
import { ref } from 'vue';
import { DocumentEditor, type TemplateVariable } from 'nuvra';

const html = ref('');

const variables: TemplateVariable[] = [
  { name: 'full_name', label: 'ФИО' },
  { name: 'position', label: 'Должность' },
  { name: 'letter_number', label: 'Номер письма' },
  { name: 'letter_date', label: 'Дата письма' }
];
</script>

<template>
  <DocumentEditor v-model="html" :variables="variables" />
</template>
```

В редакторе переменная отображается как один чип (плашка) с её подписью. Он ведёт себя как один символ: Backspace и Delete удаляют его целиком, а полужирный, курсив, цвет или размер шрифта, применённые вокруг него, позже применяются и к подставленному значению.

`Editor` принимает тот же пропс. Ref шаблона `DocumentEditor` также предоставляет метод `insertVariable(name)` — например, для собственной боковой панели со списком переменных.

### Как сохраняются переменные

В сохранённом HTML каждая переменная хранится как небольшой элемент с обычным текстом внутри:

```html
<p>Уважаемый <strong><span data-variable="full_name">{{full_name}}</span></strong>!</p>
```

Чип, имени которого нет в `variables`, остаётся в документе и подсвечивается оранжевым, поэтому шаблон, загруженный с устаревшим списком переменных, не ломается.

### Заполнение шаблона

`fillTemplate` заменяет переменные значениями. Значения экранируются для HTML, поэтому пользовательский ввод не может внедрить разметку, а переводы строк превращаются в `<br>`.

```ts
import { fillTemplate } from 'nuvra';

const letter = fillTemplate(template, {
  full_name: 'Азиз Каримов',
  position: 'Директор',
  letter_number: '01-12/345',
  letter_date: '14.09.2026'
});
```

По умолчанию переменная без значения сохраняется, так что результат остаётся шаблоном. Другое поведение задаётся параметром `missing`:

| `missing` | Результат |
| --- | --- |
| `'keep'` (по умолчанию) | Переменная остаётся на месте. |
| `'empty'` | Переменная удаляется. |
| `'name'` | Записывается `{{name}}` обычным текстом. |

`getTemplateVariables(html)` возвращает список переменных, используемых в шаблоне, — например, чтобы построить форму для ввода их значений.

### Заполнение на сервере

`fillTemplate` — обычная функция над строками без обращения к DOM, поэтому она работает и в Node. Любой другой бэкенд может заполнить шаблон, заменяя элемент целиком:

```java
String result = template.replaceAll(
    "<span[^>]*data-variable=\"full_name\"[^>]*>[^<]*</span>",
    Matcher.quoteReplacement(HtmlUtils.htmlEscape(fullName))
);
```

## Заполнение шаблона как формы

`DocumentForm` показывает сохранённый шаблон так, как он будет напечатан, но на месте каждой переменной выводит поле ввода. Больше ничего редактировать нельзя, поэтому компонент подходит тем, кто только заполняет документы, а сам шаблон составляется в `DocumentEditor`.

```vue
<script setup lang="ts">
import { ref } from 'vue';
import { DocumentForm, type TemplateVariable } from 'nuvra';

const props = defineProps<{ template: string; variables: TemplateVariable[] }>();

const values = ref<Record<string, string>>({ letter_date: '14.09.2026' });
const form = ref<InstanceType<typeof DocumentForm>>();

const submit = async () => {
  if (form.value?.validate().length) return;
  const html = form.value?.getHTML();
  await fetch('/api/letters', { method: 'POST', body: html });
};
</script>

<template>
  <DocumentForm ref="form" v-model="values" :template="props.template" :variables="props.variables" />
  <button type="button" @click="submit">Отправить</button>
</template>
```

- `v-model` хранит значения по именам переменных. Переменная, которая встречается несколько раз, вводится один раз: все её поля используют общее значение.
- В пустом поле отображается подпись переменной из `variables`. Переменные встроенных шаблонов документов подписаны и без этого — на языке `locale`.
- Поля сохраняют форматирование вокруг переменной, например полужирный или увеличенный шрифт, и растягиваются по мере ввода текста.
- `validate()` возвращает имена незаполненных переменных, выделяет их поля красным и переводит фокус на первое из них. Пустой список означает, что форма заполнена полностью.
- `getHTML(options?)` возвращает заполненный документ, созданный с помощью `fillTemplate`: значения экранируются, а `options.missing` определяет, что делать с переменными без значения.
- `readonly` показывает заполненные значения без возможности их изменить — например, на странице согласования.

## Шаблоны документов

Кнопка документа на панели инструментов вставляет готовый документ на языке редактора: служебное письмо, приказ, заявление, справку с места работы или акт. Каждый из них оформлен так, как обычно оформляются такие документы, и использует переменные шаблона, например `{{org_name}}` и `{{doc_number}}`, поэтому его можно сразу заполнить с помощью `fillTemplate`. Чипы этих переменных подписаны, даже если их нет в `variables`.

Те же шаблоны доступны и из кода:

```ts
import { getDocumentTemplate } from 'nuvra';

const { html, variables } = getDocumentTemplate('order', 'uz');
```

## Суммы, даты и алфавиты

В меню **Другие элементы** есть три помощника для официальных текстов:

- **Сумма прописью** переписывает число непосредственно перед курсором или выделенную сумму: `15 000 000 so‘m` превращается в `15 000 000 (o‘n besh million) so‘m`. Слова пишутся на языке редактора; сотые доли остаются цифрами.
- **Сегодняшняя дата** вставляет `14.09.2026`, а **Сегодняшняя дата (полностью)** — дату в развёрнутой форме: `2026-yil 14-sentabr`, `2026 йил 14 сентябрь`, `14 сентября 2026 г.` или `14 September 2026`.

Меню регистра переводит узбекский текст с латиницы на кириллицу и обратно: выделенный фрагмент или весь документ, если ничего не выделено. Форматирование сохраняется, а переменные не затрагиваются.

Эти помощники экспортируются и для использования в вашем коде:

```ts
import { formatAmountInWords, formatLongDate, numberToWords, parseAmount, transliterate } from 'nuvra';

numberToWords(2500, 'ru'); // 'две тысячи пятьсот'
formatAmountInWords(1250.5, 'uz'); // '1 250,50 (bir ming ikki yuz ellik)'
parseAmount('1 250,50'); // 1250.5
formatLongDate(new Date(), 'uz-Cyrl'); // '2026 йил 14 сентябрь'
transliterate('O‘zbekiston', 'toCyrillic'); // 'Ўзбекистон'
```

## Блоки подписи

Кнопка с пером на панели инструментов вставляет блок подписи на языке редактора:

| Блок | Содержимое |
| --- | --- |
| Строка подписи | Должность, линия для подписи и ФИО в одной строке. |
| Блок «УТВЕРЖДАЮ» | Справа: УТВЕРЖДАЮ, должность, подпись с расшифровкой и дата. |
| Блок «СОГЛАСОВАНО» | Такой же блок слева с заголовком СОГЛАСОВАНО. |
| Подписи сторон | Заказчик и исполнитель рядом: организация, должность, подпись и место печати (М.П.). |

Блок подписи — это таблица без границ. Во время редактирования её ячейки на странице обозначены бледными пунктирными линиями; при печати, в PDF и при экспорте в Word границ нет. Весь текст в блоке — обычное содержимое: замените текст-заполнитель, добавьте строки через меню таблицы или вставьте переменные шаблона, например `{{full_name}}` рядом с линией для подписи.
