# Начало работы

nuvra — редактор документов в стиле Word для Vue 3. Эта страница за несколько минут проведёт вас от установки до работающего редактора.

## Требования

- Vue 3.5 или новее. Vue — единственная peer-зависимость; UI-фреймворк для nuvra не нужен.
- Актуальный автоматически обновляемый браузер (Chrome, Edge, Safari или Firefox). Подробности — в разделе [Поддержка браузеров](/docs/browser-support).

## Установка

Установите пакет с помощью своего пакетного менеджера:

```sh
pnpm add nuvra
# или
npm install nuvra
# или
yarn add nuvra
```

## Подключение стилей

Стили редактора поставляются отдельным файлом. Импортируйте его один раз, например в `main.ts`:

```ts
import { createApp } from 'vue';
import 'nuvra/style.css';

import App from './App.vue';

createApp(App).mount('#app');
```

## Ваш первый редактор документов

`DocumentEditor` — полноценный редактор: панель инструментов, страничный режим с размерами бумаги и полями, строка состояния, поиск и замена, печать и экспорт. Привяжите HTML документа через `v-model`:

```vue
<script setup lang="ts">
import { ref } from 'vue';
import { DocumentEditor } from 'nuvra';

const html = ref('<p>Привет, <strong>nuvra</strong>!</p>');
</script>

<template>
  <DocumentEditor v-model="html" title="Мой первый документ" />
</template>
```

По умолчанию высота редактора — 760 px. Передайте в `height` число (в пикселях) или любую длину CSS, например `height="100%"` внутри контейнера с заданной высотой.

## Поле форматированного текста для форм

`Editor` — тот же редактор в более лёгком веб-режиме. Он растёт вместе с содержимым от `minHeight` (240 px) до `maxHeight` (600 px), поэтому хорошо подходит для полей форм:

```vue
<script setup lang="ts">
import { ref } from 'vue';
import { Editor } from 'nuvra';

const description = ref('');
</script>

<template>
  <Editor v-model="description" placeholder="Опишите должность" :max-length="2000" />
</template>
```

У пустого поля значение `''`, поэтому обычная проверка на обязательность работает без дополнительных условий.
