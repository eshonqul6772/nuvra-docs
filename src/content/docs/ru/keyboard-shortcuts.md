# Сочетания клавиш

nuvra поддерживает сочетания клавиш привычных текстовых редакторов и во время набора преобразует последовательности в стиле Markdown. Всплывающие подсказки на панели инструментов показывают сочетание для каждой команды.

## Особенности платформ

В таблицах указаны клавиши для Windows и Linux. В macOS используйте `⌘` вместо `Ctrl` и `⌥` вместо `Alt`. Сочетания определяются по физической клавише, поэтому работают и в кириллической, и в других раскладках клавиатуры.

## История

| Сочетание | Действие |
| --- | --- |
| `Ctrl+Z` | Отмена |
| `Ctrl+Y` или `Ctrl+Shift+Z` | Повтор |

## Форматирование текста

| Сочетание | Действие |
| --- | --- |
| `Ctrl+B` | Полужирный |
| `Ctrl+I` | Курсив |
| `Ctrl+U` | Подчёркнутый |
| `Ctrl+Shift+S` | Зачёркнутый |
| `Ctrl+E` | Встроенный код |
| `Ctrl+,` | Подстрочный |
| `Ctrl+.` | Надстрочный |
| `Ctrl+Shift+H` | Выделение цветом |

Если текст не выделен, сочетание форматирования применяется к тексту, который вы наберёте дальше.

## Абзацы и заголовки

| Сочетание | Действие |
| --- | --- |
| `Ctrl+Alt+0` | Обычный текст |
| `Ctrl+Alt+1` … `Ctrl+Alt+6` | Заголовок от 1 до 6 |
| `Ctrl+Shift+B` | Цитата |
| `Ctrl+Alt+C` | Блок кода |
| `Ctrl+Shift+L` | По левому краю |
| `Ctrl+Shift+E` | По центру |
| `Ctrl+Shift+R` | По правому краю |
| `Ctrl+Shift+J` | По ширине |
| `Enter` | Новый абзац |
| `Shift+Enter` | Перенос строки внутри абзаца |
| `Ctrl+Enter` | Разрыв страницы |
| `Tab` / `Shift+Tab` | В начале абзаца: увеличить или уменьшить отступ. Внутри строки `Tab` вставляет символ табуляции. |

## Списки

| Сочетание | Действие |
| --- | --- |
| `Ctrl+Shift+8` | Маркированный список |
| `Ctrl+Shift+7` | Нумерованный список |
| `Ctrl+Shift+9` | Список задач |
| `Tab` / `Shift+Tab` | Сдвинуть пункт списка на уровень ниже или выше |

## Таблицы

| Сочетание | Действие |
| --- | --- |
| `Tab` | Перейти к следующей ячейке; в последней ячейке — добавить новую строку |
| `Shift+Tab` | Перейти к предыдущей ячейке |
| `Delete` / `Backspace` | Очистить выделенные ячейки |
| `Escape` | Снять выделение ячеек |

Чтобы выделить прямоугольную область ячеек, протяните по ним мышью.

## Изображения и ссылки

| Сочетание | Действие |
| --- | --- |
| `Delete` / `Backspace` | Удалить выделенное изображение |
| `Escape` | Снять выделение с изображения |
| `Ctrl+click` | Открыть ссылку под указателем в новой вкладке |

## Редактор

| Сочетание | Действие |
| --- | --- |
| `Ctrl+F` | Найти |
| `Ctrl+H` | Найти и заменить |
| `Enter` / `Shift+Enter` | В поле поиска: следующее или предыдущее совпадение |
| `Enter` | В поле замены: заменить текущее совпадение |
| `Ctrl+K` | Вставить или изменить ссылку |
| `Ctrl+Alt+M` | Добавить комментарий к выделенному тексту, если комментарии включены |
| `Ctrl+Enter` | В форме комментария, ответа или сноски: сохранить |
| `Escape` | В форме комментария, ответа или сноски: закрыть без сохранения |
| `Ctrl+P` | Печать |
| `Ctrl+` колесо мыши | Увеличить или уменьшить масштаб документа |
| `Right click` | Открыть контекстное меню для элемента под указателем |
| `Escape` | Закрыть открытое меню или всплывающее окно, панель поиска, отменить формат по образцу или выйти из полноэкранного режима |

## Меню /

Наберите `/` в начале строки или после пробела, чтобы открыть меню команд, а затем вводите буквы для фильтрации.

| Сочетание | Действие |
| --- | --- |
| `↑` / `↓` | Перемещение по командам |
| `Enter` или `Tab` | Выполнить выделенную команду |
| `Escape` | Закрыть меню |

## Правила ввода в стиле Markdown

Эти последовательности преобразуются автоматически при наборе. Внутри кода правила не применяются.

### В начале абзаца

| Ввод | Результат |
| --- | --- |
| от `#` до `######` и пробел | Заголовок от 1 до 6 |
| `-`, `+` или `*` и пробел | Маркированный список |
| `1.` и пробел | Нумерованный список; с другим числом список начинается с него |
| `[ ]` или `[x]` и пробел | Пункт списка задач, с `x` — отмеченный |
| `>` и пробел | Цитата |
| `` ``` `` | Блок кода |
| `---` | Горизонтальная линия |
| `___` или `***` и пробел | Горизонтальная линия |

### Встроенное форматирование

| Ввод | Результат |
| --- | --- |
| `**text**` или `__text__` | Полужирный |
| `*text*` или `_text_` | Курсив |
| `~~text~~` | Зачёркнутый |
| `==text==` | Выделение цветом |
| `` `text` `` | Встроенный код |

После закрывающих символов следующий набираемый текст уже не форматируется.

### Ссылки

Веб-адрес, начинающийся с `http://`, `https://` или `www.`, становится ссылкой, когда после него вводится пробел. К адресам, начинающимся с `www.`, добавляется `https://`.

### Типографика

| Ввод | Результат |
| --- | --- |
| `--` | — |
| `...` | … |
| `->` | → |
| `<-` | ← |
| `>>` | » |
| `<<` | « |
| `(c)` | © |
| `(r)` | ® |
| `(tm)` | ™ |
| `(sm)` | ℠ |
| `+/-` | ± |
| `!=` | ≠ |
| `3x4` или `3 * 4` | 3×4 или 3 × 4 |
| `"` и `'` | Типографские кавычки “ ” и ‘ ’ |
