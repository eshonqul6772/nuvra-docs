# Поддержка браузеров

nuvra рассчитан на актуальные автоматически обновляемые браузеры: Chrome, Edge, Safari и Firefox. Он использует несколько современных возможностей веб-платформы и корректно работает с ограничениями там, где какой-то из них нет.

## Popover API

Меню, всплывающие окна и плавающие панели инструментов для ссылок, изображений и таблиц используют [Popover API](https://developer.mozilla.org/docs/Web/API/Popover_API). Он выводит их в верхнем слое браузера, поэтому они отображаются поверх диалогов, модальных окон и полноэкранного редактора без какой-либо настройки z-index.

| Браузер | Версия |
| --- | --- |
| Chrome и Edge | 114+ |
| Safari | 17+ |
| Firefox | 125+ |

В браузерах без Popover API эти панели вместо этого отображаются как фиксированные элементы с большим z-index. Они по-прежнему работают, но модальное окно вашего приложения с ещё большим z-index может их перекрыть.

## CSS Custom Highlight API

Поиск и замена подсвечивает совпадения с помощью [CSS Custom Highlight API](https://developer.mozilla.org/docs/Web/API/CSS_Custom_Highlight_API), который выделяет текст, не изменяя документ. Там, где этот API недоступен, поиск всё равно подсчитывает совпадения, переходит между ними и заменяет их — просто совпадения не подсвечиваются.

## Контейнерные запросы

Панель поиска и строка состояния используют контейнерные запросы CSS, чтобы переключаться на компактную раскладку, когда редактор узкий, например в боковой панели или на телефоне. В браузерах без контейнерных запросов сохраняется обычная раскладка.

## Буфер обмена и перетаскивание

Копирование, вырезание, вставка и перетаскивание используют стандартные события буфера обмена и перетаскивания. Разрешение на доступ к буферу обмена не запрашивается, а вставляемое содержимое очищается перед вставкой.

## Печать и экспорт

Для печати документ отрисовывается в скрытом фрейме и открывается собственный диалог печати браузера, где пользователи также могут сохранить PDF. Экспорт в HTML и Word создаёт файл в браузере и скачивает его; сервер не участвует.

## Устаревшие браузеры

Internet Explorer и другие устаревшие браузеры не поддерживаются.
