# Комментарии и сравнение

Документы редко пишет один человек. В nuvra рецензенты могут оставлять **комментарии** к фрагментам текста, правки записываются как **отслеживаемые изменения**, которые можно принять или отклонить, а отдельный компонент показывает, что изменилось между двумя **версиями** документа.

## Комментарии

### Включение комментариев

Привяжите список к `v-model:comments`. Инструменты комментирования появляются только при наличии этой привязки, поэтому редактор без неё выглядит как прежде. `author` — имя, которое записывается в новые комментарии, ответы и отслеживаемые изменения.

```vue
<script setup lang="ts">
import { ref } from 'vue';
import { DocumentEditor, type DocumentComment } from 'nuvra';

const html = ref('');
const comments = ref<DocumentComment[]>([]);
</script>

<template>
  <DocumentEditor v-model="html" v-model:comments="comments" author="Aziz Karimov" />
</template>
```

Начинайте с пустого массива: при `undefined` инструменты остаются скрытыми.

### Работа с комментариями

Инструменты комментирования находятся в меню **Рецензирование** в правой части панели инструментов (облачко со стрелкой; подсказка «Рецензирование: примечания и исправления»), под пунктами отслеживаемых изменений:

- **Добавить примечание** привязывает комментарий к выделенному тексту и открывает форму. Для этого нужно выделить текст; сочетание клавиш — `Ctrl+Alt+M`. `Ctrl+Enter` сохраняет комментарий, а `Escape` или **Отмена** удаляет его вместе с привязкой.
- **Примечания** открывает и закрывает панель со всеми комментариями в порядке их расположения в тексте.

На панели:

| Действие | Результат |
| --- | --- |
| Щелчок по комментарию | Выделяет его текст в документе и прокручивает к нему. |
| **Ответить** | Добавляет ответ в обсуждение. |
| **Решено** / **Открыть снова** | Закрывает или снова открывает обсуждение. Решённый комментарий сохраняет привязку, но его текст больше не подсвечивается. |
| Удаление (кнопка с корзиной) | Удаляет комментарий и его привязку; сам текст остаётся. |

Если поставить курсор в прокомментированный текст, соответствующий комментарий подсвечивается на панели. Если прокомментированный текст удалить, комментарий остаётся в списке с пометкой «Текст примечания удалён»; отмена возвращает и текст, и привязку.

В редакторе с `disabled` комментарии можно читать, но нельзя добавлять или изменять.

### Как сохраняются комментарии

В HTML документа хранятся только привязки:

```html
<p>Исполнитель сдаёт работу <span data-comment="cmfz3k1a9x2b7q">в течение 30 дней</span>.</p>
```

Сами комментарии — обычные данные в вашем списке:

```json
[
  {
    "id": "cmfz3k1a9x2b7q",
    "text": "Имеются в виду рабочие дни?",
    "author": "Aziz Karimov",
    "createdAt": "2026-09-14T09:30:00.000Z",
    "resolved": false,
    "replies": [
      { "id": "cmfz3m8d0p1k2c", "text": "Да, 30 рабочих дней.", "author": "Dilnoza Rahimova", "createdAt": "2026-09-14T10:05:00.000Z" }
    ]
  }
]
```

Подсветка отображается только внутри редактора. При печати и экспорте в HTML текст выводится без неё, а экспорт в Word записывает текст без комментариев.

### Сохранение на сервере

Храните список комментариев рядом с документом и загружайте их вместе:

```vue
<script setup lang="ts">
import { onMounted, ref } from 'vue';
import { DocumentEditor, type DocumentComment, type PageSettings, createPageSettings } from 'nuvra';

interface StoredDocument {
  html: string;
  page: PageSettings;
  comments: DocumentComment[];
}

const html = ref('');
const page = ref<PageSettings>(createPageSettings());
const comments = ref<DocumentComment[]>([]);
const editor = ref<InstanceType<typeof DocumentEditor>>();

onMounted(async () => {
  const response = await fetch('/api/documents/42');
  const stored: StoredDocument = await response.json();
  html.value = stored.html;
  page.value = stored.page;
  comments.value = stored.comments ?? [];
});

const save = async () => {
  const body: StoredDocument = {
    html: editor.value?.getHTML() ?? html.value,
    page: page.value,
    comments: comments.value
  };
  await fetch('/api/documents/42', {
    method: 'PUT',
    headers: { 'Content-Type': 'application/json' },
    body: JSON.stringify(body)
  });
};
</script>

<template>
  <DocumentEditor
    ref="editor"
    v-model="html"
    v-model:page="page"
    v-model:comments="comments"
    author="Aziz Karimov"
  />
  <button type="button" @click="save">Сохранить</button>
</template>
```

На сервере комментарии можно хранить в JSON-столбце таблицы документов или в отдельной таблице с ключом по документу и `id` комментария.

- `getHTML()` фиксирует последние правки перед сохранением, поэтому привязки в HTML соответствуют списку.
- Список меняется при каждом добавлении, ответе, закрытии и удалении. Сохраняйте его вместе с документом или отслеживайте с помощью `watch(comments, save, { deep: true })`.
- Комментарии, текст которых удалён, не удаляются автоматически, поскольку отмена может вернуть текст. Чтобы убрать их, когда документ готов, оставьте только те идентификаторы, которые ещё есть в HTML:

```ts
const anchored = new Set(Array.from(html.matchAll(/data-comment="([\w-]+)"/g), match => match[1]));
const kept = comments.filter(comment => anchored.has(comment.id));
```

`createCommentId()` создаёт идентификаторы в том же формате — для комментариев, которые добавляет ваш собственный код.

## Отслеживаемые изменения

### Включение отслеживания

Привяжите `v-model:trackChanges` или дайте пользователям выбирать пункт «Запись исправлений» в меню **Рецензирование** на панели инструментов. Пока отслеживание включено, набранный текст помечается как вставленный, а удалённый текст остаётся в документе с пометкой удаления, пока кто-нибудь не примет или не отклонит изменение. В каждое изменение записывается `author`.

```vue
<script setup lang="ts">
import { ref } from 'vue';
import { DocumentEditor } from 'nuvra';

const html = ref('');
const trackChanges = ref(true);
</script>

<template>
  <DocumentEditor v-model="html" v-model:track-changes="trackChanges" author="Aziz Karimov" />
</template>
```

По умолчанию отслеживание выключено. Пункт «Запись исправлений» недоступен, пока редактор находится в состоянии `disabled`. Кнопка «Рецензирование» подсвечивается, пока отслеживание включено или открыта одна из панелей рецензирования.

### Как сохраняются изменения

Изменения являются частью HTML документа, поэтому их сохраняет `v-model`, и больше ничего хранить не нужно:

```html
<p>Исполнитель сдаёт работу в течение
  <del data-change="tmfz3k1a9x2b" data-author="Aziz Karimov" data-time="2026-09-14T09:30:00Z">30</del><ins data-change="tmfz3k1a9x2b" data-author="Aziz Karimov" data-time="2026-09-14T09:30:00Z">45</ins>
  дней.</p>
```

- Вставленный текст выделяется зелёным цветом и подчёркиванием, удалённый — красным цветом и зачёркиванием: в редакторе, при печати и в экспорте в HTML.
- Набираемый текст добавляется к одному изменению, пока курсор не переместится, поэтому набранное слово — это одно изменение, а не отдельное для каждой буквы.
- Удалённый текст остаётся в HTML. Примите или отклоните изменения, прежде чем использовать документ как окончательный.
- Вставленные `<ins>` и `<del>` без `data-change` становятся обычным подчёркиванием и зачёркиванием.

### Просмотр изменений

Пункт «Исправления» в меню **Рецензирование** открывает панель со всеми изменениями в порядке документа: был ли текст вставлен или удалён, автор, время и сам текст.

| Действие | Результат |
| --- | --- |
| Щелчок по изменению | Выделяет его текст в документе и прокручивает к нему. |
| **Принять** | Оставляет вставку как обычный текст или окончательно удаляет удалённый текст. |
| **Отклонить** | Удаляет вставку или восстанавливает удалённый текст. |
| **Принять все** / **Отклонить все** | Делает то же самое для всех изменений в документе. |

Каждое принятие или отклонение — отдельный шаг отмены. В редакторе с `disabled` изменения можно просматривать, но нельзя принимать или отклонять.

### Из кода

Движок из ref шаблона читает и обрабатывает изменения — например, чтобы принять всё перед публикацией:

```ts
const editor = ref<InstanceType<typeof DocumentEditor>>();

const publish = async () => {
  const engine = editor.value?.engine;
  if (!engine) return;
  const changes = engine.getChanges(); // TrackedChange[]: id, type, author, time, text
  if (changes.length && !confirm(`Принять изменения (${changes.length})?`)) return;
  engine.resolveChanges(true);
  await fetch('/api/documents/42/publish', { method: 'POST', body: editor.value?.getHTML() });
};
```

`resolveChanges(accept, id)` обрабатывает одно изменение, а `selectChange(id)` показывает его в документе.

### Что отслеживается

| Отслеживается | Не отслеживается |
| --- | --- |
| Набор текста, в том числе через методы ввода (IME) | Форматирование: полужирный, цвета, шрифты, выравнивание |
| Удаление символов, слов и строк клавишами Backspace и Delete | Изменения блоков: заголовки, списки, таблицы, разрывы страниц |
| Удаление или замена выделенного фрагмента | Объединение двух абзацев клавишей Backspace или Delete на их границе |
| Вырезание, вставка, перетаскивание | Enter |
| Текст, вставленный командами, которые добавляют текст или содержимое, например даты, блоки подписи и шаблоны документов | Поиск и замена, сноски и переменные шаблона |

Если автор удаляет текст, который сам вставил при включённом отслеживании, текст удаляется окончательно, как в Word, а Backspace перешагивает через текст, уже помеченный как удалённый.

### Обмен с Word

Экспорт в Word записывает отслеживаемые изменения как исправления Word с автором и временем, а при открытии файла Word его исправления снова становятся отслеживаемыми изменениями. Документ можно отправить в Word на рецензирование и получить обратно с по-прежнему открытыми изменениями. Переносятся только вставки и удаления текста: текст, помеченный в Word как перемещённый, возвращается удалением на старом месте и вставкой на новом, а изменение форматирования, записанное в Word, приходит как новое форматирование без исправления.

## Сравнение версий

`DocumentCompare` показывает на одном листе, что изменилось между двумя версиями документа: новую версию, в которой вставленные слова подчёркнуты зелёным, а удалённые зачёркнуты красным. Над ней выводится статистика, например «Вставлено слов: 12» и «Удалено слов: 3», или «Версии совпадают».

```vue
<script setup lang="ts">
import { DocumentCompare } from 'nuvra';

defineProps<{ previous: string; current: string }>();
</script>

<template>
  <DocumentCompare :before="previous" :after="current" :height="600" />
</template>
```

Храните HTML каждой сохранённой версии на своём сервере — например, при каждом согласовании — и передавайте две из них компоненту. Компонент доступен только для чтения.

### Как сравниваются версии

| Изменение | Как отображается |
| --- | --- |
| Неизменённый блок | Как есть, со своим форматированием. |
| Абзац, заголовок или блок кода с изменённым текстом | Сравнивается пословно; изменённые слова помечаются. |
| Добавленный или удалённый блок | Весь блок с зелёной или красной полосой сбоку. |
| Изменённый список, таблица, цитата или изображение | Старый блок — как удалённый, новый — как добавленный. |

- Изменённый абзац сохраняет свой тип и выравнивание, но его строчное форматирование (полужирный, цвета, ссылки) не отображается.
- Изменение только форматирования не помечает ни одного слова и не учитывается в статистике.
- Абзац, ставший заголовком, или наоборот, отображается как удалённый и добавленный блок.

### Собственное представление

`compareDocuments(before, after)` возвращает тот же результат для вашей собственной разметки: `html` с пометками, а также количества `insertions` и `deletions`. Слова помечаются с помощью `<ins class="doc-diff-ins">` и `<del class="doc-diff-del">`, целые блоки оборачиваются в `<div class="doc-diff-block doc-diff-block--ins">` или `doc-diff-block--del`. HTML строится из очищенных блоков и экранированного текста. Функции нужен DOM, поэтому она работает в браузере.
