# Использование

На этой странице описана повседневная работа с `DocumentEditor` и `Editor`: значение, параметры страницы, режимы просмотра, меню `/`, размеры, изображения, собственные кнопки на панели инструментов, печать и экспорт. Полный список параметров — в разделе [API](/docs/api).

## Значение документа

`v-model` хранит документ в виде HTML.

- Пустой документ записывается как пустая строка `''`.
- Пока пользователь печатает, значение обновляется после короткой паузы (около 200 мс), потому что сериализация всего документа при каждом нажатии клавиши обходится дорого. Несохранённые правки записываются сразу, когда редактор теряет фокус, и перед его размонтированием.
- `getHTML()`, вызванный через ref шаблона, записывает несохранённые правки и возвращает текущий HTML, поэтому его можно смело вызывать непосредственно перед сохранением.
- Если присвоить новое значение извне, документ будет заменён. Сначала HTML очищается, и остаётся только разметка, которую поддерживает редактор.

```vue
<script setup lang="ts">
import { ref } from 'vue';
import { DocumentEditor } from 'nuvra';

const html = ref('<p>Загружено с сервера</p>');

const save = () => fetch('/api/documents/1', { method: 'PUT', body: html.value });
</script>

<template>
  <DocumentEditor v-model="html" @blur="save" />
</template>
```

## Параметры страницы

Размер бумаги, ориентация и поля привязываются через `v-model:page`. `createPageSettings()` возвращает значения по умолчанию: A4, книжная ориентация, обычные поля.

```vue
<script setup lang="ts">
import { ref } from 'vue';
import { DocumentEditor, type PageSettings, createPageSettings } from 'nuvra';

const html = ref('');
const page = ref<PageSettings>(createPageSettings());
</script>

<template>
  <DocumentEditor v-model="html" v-model:page="page" />
</template>
```

Пользователи меняют настройки во всплывающем окне параметров страницы на панели инструментов. Поля задаются в миллиметрах (0–100 в полях для точного значения).

### Размеры бумаги

| Ключ | Название | Размер (книжная, мм) |
| --- | --- | --- |
| `a3` | A3 | 297 × 420 |
| `a4` | A4 | 210 × 297 |
| `a5` | A5 | 148 × 210 |
| `letter` | Letter | 215.9 × 279.4 |
| `legal` | Legal | 215.9 × 355.6 |

### Готовые наборы полей

| Набор | Верхнее | Правое | Нижнее | Левое |
| --- | --- | --- | --- | --- |
| Обычные (по умолчанию) | 25.4 | 25.4 | 25.4 | 25.4 |
| Узкие | 12.7 | 12.7 | 12.7 | 12.7 |
| Средние | 25.4 | 19.1 | 25.4 | 19.1 |
| Широкие | 25.4 | 50.8 | 25.4 | 50.8 |
| Официальный документ (O‘zDSt 1.14) | 20 | 15 | 20 | 30 |

Те же настройки используются при печати и при экспорте в HTML и Word.

## Колонтитулы

Кнопка колонтитулов на панели инструментов редактирует повторяющийся текст вверху и внизу каждой страницы; в каждом колонтитуле есть левая, центральная и правая части. Оба колонтитула хранятся в параметрах страницы как `header` и `footer`, поэтому `v-model:page` сохраняет и восстанавливает их вместе с остальными настройками.

| Токен | Заменяется на |
| --- | --- |
| `{page}` | Номер текущей страницы |
| `{pages}` | Число страниц в документе |
| `{date}` | Сегодняшняя дата (дд.мм.гггг) |
| `{title}` | Название документа из пропса `title` |

- В страничном режиме колонтитулы выводятся в полях каждого листа, а токены вычисляются для этой страницы. Нижний колонтитул заменяет собственный индикатор страницы редактора.
- При печати и экспорте в HTML документ разбивается на листы точно так же, как в редакторе, поэтому номера страниц и разрывы страниц на бумаге совпадают с экраном.
- При экспорте в Word колонтитулы становятся собственными колонтитулами Word, а `{page}` и `{pages}` — полями Word PAGE и NUMPAGES, поэтому номера остаются верными и после редактирования документа в Word.
- При экспорте из веб-режима документ не разбивается на листы: колонтитулы по-прежнему повторяются на каждой печатной странице, но `{page}` остаётся пустым.
- В том же окне можно скрыть колонтитулы на первой странице и задать номер первой страницы; см. [Нумерация страниц](/docs/word-files#нумерация-страниц).

## Водяной знак

Если ввести текст в разделе «Водяной знак» параметров страницы (например, `ЧЕРНОВИК` или `КОПИЯ`), он будет бледно отображаться за текстом каждой страницы. Цвет можно выбрать, а переключатель «По диагонали» располагает текст на странице под углом.

- Текст масштабируется по размеру листа и выводится с непрозрачностью 16%, поэтому не мешает чтению.
- Он хранится в параметрах страницы как `watermark`, поэтому `v-model:page` сохраняет и восстанавливает его вместе с остальными настройками.
- При печати и экспорте в HTML водяной знак повторяется на каждом листе; при экспорте в Word он записывается в собственном формате водяного знака Word (VML-фигура внутри верхнего колонтитула).
- Если очистить текст, водяной знак снова удаляется из настроек.

## Линейка

В страничном режиме над листом расположена линейка: она размечена в сантиметрах, отделяет область текста от полей и содержит пять перетаскиваемых маркеров.

| Маркер | Что меняет |
| --- | --- |
| Треугольник сверху | Отступ первой строки абзаца (`text-indent`) |
| Левый треугольник снизу | Левый отступ абзаца (`margin-left`) |
| Правый треугольник снизу | Правый отступ абзаца (`margin-right`) |
| Левая планка посередине | Левое поле страницы |
| Правая планка посередине | Правое поле страницы |

- Значения округляются до целых миллиметров и применяются, когда кнопка мыши отпущена, поэтому одно перетаскивание — это один шаг отмены.
- Маркеры отступов действуют на абзац, в котором стоит курсор (или на выделенные абзацы); маркеры полей меняют поля в `v-model:page`.
- `:ruler="false"` скрывает линейку с самого начала; пользователи включают и выключают её пунктом «Линейка» в меню «Ещё». В веб-режиме и в поле формы линейка не отображается.

## Режимы просмотра

У редактора два режима, которые переключаются в строке состояния:

- **Страничный режим** (`'page'`) показывает отдельные листы с выбранным размером бумаги и полями, счётчик страниц и масштаб от 30% до 200% с шагом 10%. В узких контейнерах страница автоматически уменьшается, пока пользователь сам не выберет масштаб.
- **Веб-режим** (`'web'`) показывает один непрерывный лист, как веб-страницу.

`defaultViewMode` задаёт режим, который показывается первым. `DocumentEditor` открывается в веб-режиме на всю ширину; передайте `page`, чтобы показать листы на сером фоне. `Editor` всегда использует веб-режим.

```vue
<template>
  <DocumentEditor v-model="html" default-view-mode="page" />
</template>
```

## Инструменты форматирования

На панели инструментов есть привычные по офисным редакторам инструменты:

- **Формат по образцу** берёт форматирование в позиции курсора (шрифт, размер, цвет, выделение цветом, полужирный и курсив, тип блока, выравнивание, междустрочный интервал и отступы) и применяет его к следующему выделенному тексту или к абзацу, по которому щёлкнули. `Escape` отменяет его.
- **Регистр** (Aa) переводит выделенный текст в ВЕРХНИЙ РЕГИСТР, нижний регистр, Каждое Слово С Прописной или режим «Как в предложениях», а также меняет регистр каждого символа на противоположный.
- **Поле размера шрифта** принимает размер, которого нет в списке (1–400 pt); кнопки A↑ и A↓ рядом с ним переключают размеры по списку.
- **Интервал между абзацами** добавляется из меню междустрочного интервала: 12 pt перед абзацем или после него. Он хранится в HTML документа в атрибутах `data-space-before` и `data-space-after` вместе с `margin`, а интервалы абзацев, вставленных из Word или Google Docs, преобразуются в ту же форму.
- **Непечатаемые знаки** включаются в меню «Ещё» и выводят знак абзаца в конце каждого абзаца. Их рисует только редактор: в HTML документа, при печати и экспорте их нет.
- **Контекстное меню** открывается по щелчку правой кнопкой мыши и зависит от того, по чему щёлкнули: вырезать, копировать и вставить, действия со ссылкой, строки и столбцы таблицы, удаление изображения, очистка форматирования и выделение всего.
- **Масштаб** меняется колёсиком мыши с зажатой клавишей `Ctrl` (`⌘` в macOS).

## Меню /

Если ввести `/` в начале строки или после пробела, под курсором откроется список команд: обычный текст, заголовки 1–3, маркированный, нумерованный список и список задач, цитата, блок кода, таблица, горизонтальная линия, разрыв страницы, сноска, оглавление, разрывы разделов для альбомных и книжных страниц, сегодняшняя дата в краткой и полной форме, блоки подписи и переменные шаблона из `variables`.

- Буквы, введённые после `/`, фильтруют список по названию и по нескольким ключевым словам на узбекском, русском и английском: `/jadval` находит таблицу.
- `↑` и `↓` перемещают по списку; `Enter`, `Tab` или щелчок выполняют команду. Введённый `/filter` сначала удаляется.
- `Escape` закрывает меню, и оно остаётся закрытым, пока не изменится текст перед курсором.
- Меню не открывается внутри блоков кода, в редакторе с `disabled` и в режиме исходного HTML. В `Editor` оно тоже есть.

### Собственные команды

`slashCommands` добавляет команды вашего приложения в начало списка. `run` получает движок редактирования:

```vue
<script setup lang="ts">
import { ref } from 'vue';
import { DocumentEditor, type SlashCommand } from 'nuvra';

const html = ref('');

const slashCommands: SlashCommand[] = [
  {
    id: 'director',
    label: 'Имя директора',
    icon: 'pencil',
    keywords: ['direktor', 'директор'],
    run: engine => engine.insertText('А. Каримов')
  },
  {
    id: 'approved',
    label: 'Гриф утверждения',
    icon: 'signature',
    run: engine => engine.insertContent('<p style="text-align: right"><strong>УТВЕРЖДАЮ</strong></p>', { asBlocks: true })
  }
];
</script>

<template>
  <DocumentEditor v-model="html" :slash-commands="slashCommands" />
</template>
```

`icon` — одно из имён иконок редактора (`IconName`); без него у команды отображается плюс. Самые полезные методы движка перечислены в разделе [DocumentEngine](/docs/api#documentengine).

## Размеры

| Пропс | По умолчанию | Описание |
| --- | --- | --- |
| `height` | `760` | Высота всего редактора или `'auto'`, чтобы он рос вместе с содержимым. |
| `minHeight` | `240` | Минимальная высота, когда `height` равен `'auto'`. |
| `maxHeight` | `600` | Максимальная высота, когда `height` равен `'auto'`; более длинные документы прокручиваются. |
| `canvasPadding` | `50` | Серое пространство вокруг страницы или веб-листа. |

Числа задаются в пикселях; строки используются как длины CSS, например `'100%'` или `'50vh'`. `Editor` всегда использует `height: 'auto'`.

Корневой элемент редактора также получает все переданные вами атрибуты, например `class` и `style`.

## Документы только для чтения

`disabled` делает документ доступным только для чтения и отключает все элементы редактирования. Поиск, параметры страницы, печать и экспорт остаются доступными.

```vue
<template>
  <DocumentEditor :model-value="html" disabled />
</template>
```

## Ограничение числа символов

`maxLength` ограничивает число символов; `0` (по умолчанию) означает отсутствие ограничения. Ввод, вставка и добавление содержимого, которые превысили бы лимит, отклоняются, а строка состояния показывает счётчик в виде `количество / лимит` и выделяет его, когда лимит достигнут.

## Текст-заполнитель

`placeholder` задаёт текст, который показывается, пока документ пуст. Без него редактор показывает встроенную подпись `editor.placeholder`.

## Изображения

Пользователи вставляют изображения с панели инструментов (загрузка с компьютера или по веб-адресу), вставкой файлов изображений из буфера обмена и перетаскиванием их в документ.

Без обработчика загрузки изображения встраиваются в HTML как data URL. Чтобы хранить их на своём сервере, передайте `uploadImage` — функцию, которая получает `File` и возвращает промис с его URL.

```vue
<script setup lang="ts">
import { ref } from 'vue';
import { DocumentEditor, type DocumentImageUploadHandler } from 'nuvra';

const html = ref('');

const uploadImage: DocumentImageUploadHandler = async file => {
  const body = new FormData();
  body.append('file', file);
  const response = await fetch('/api/files', { method: 'POST', body });
  return (await response.json()).url;
};

const onUploadError = (error: unknown) => {
  console.error(error);
};
</script>

<template>
  <DocumentEditor v-model="html" :upload-image="uploadImage" :max-image-size-mb="5" @upload-error="onUploadError" />
</template>
```

- Принимаются только файлы с типом `image/*`.
- Файлы больше `maxImageSizeMb` (по умолчанию 10 МБ) отклоняются.
- Несколько изображений обрабатываются по очереди, при этом отображается индикатор «загрузка».
- Отклонённый файл, неудачная загрузка или пустой URL от обработчика вызывают событие `uploadError` с ошибкой; остальные изображения всё равно вставляются. Ошибки проверки — это объекты `Error` с переведённым сообщением.
- Адреса изображений, вводимые на панели инструментов, должны начинаться с `http://`, `https://` или `/`.

## Методы ref шаблона

`DocumentEditor` предоставляет несколько методов через ref шаблона:

```vue
<script setup lang="ts">
import { ref } from 'vue';
import { DocumentEditor } from 'nuvra';

const html = ref('');
const editor = ref<InstanceType<typeof DocumentEditor>>();

const save = () => {
  const latest = editor.value?.getHTML();
  // отправьте `latest` на сервер
};
</script>

<template>
  <DocumentEditor ref="editor" v-model="html" />
  <button type="button" @click="save">Сохранить</button>
  <button type="button" @click="editor?.print()">Печать</button>
</template>
```

| Член | Описание |
| --- | --- |
| `focus()` | Переводит фокус клавиатуры в документ. |
| `getHTML()` | Записывает несохранённые правки в модель и возвращает HTML документа. |
| `insertVariable(name)` | Вставляет переменную шаблона в место выделения. |
| `updateTableOfContents()` | Вставляет или обновляет оглавление. |
| `importWord(file)` | Заменяет документ содержимым файла `.docx`. |
| `importPdf(file)` | Заменяет документ содержимым файла `.pdf` в виде редактируемого текста. |
| `print()` | Открывает диалог печати браузера для документа. |
| `exportHtml()` | Скачивает документ в виде самостоятельной HTML-страницы. |
| `exportWord()` | Скачивает документ в виде файла Word (`.docx`). |
| `exportPdf()` | Скачивает документ как PDF, отрисованный из его страниц (новое в 0.6.0). |
| `engine` | Движок редактирования (`null`, пока редактор не смонтирован) для сложных интеграций. |

`Editor` эти методы не предоставляет.

## Собственные кнопки на панели инструментов

Слот `toolbar` размещает кнопки вашего приложения в начале правой группы панели инструментов. Он получает движок редактирования `engine`, состояние форматирования `state` в позиции курсора и `disabled`, который равен `true`, пока документ нельзя редактировать.

```vue
<script setup lang="ts">
import { ref } from 'vue';
import { DocumentEditor } from 'nuvra';

const html = ref('');

const lookUp = (text: string) => window.open(`https://www.google.com/search?q=${encodeURIComponent(text)}`);
</script>

<template>
  <DocumentEditor v-model="html">
    <template #toolbar="{ engine, state, disabled }">
      <button
        type="button"
        class="doc-tb-button"
        title="Вставить отметку о получении"
        :disabled="disabled"
        @mousedown.prevent
        @click="engine.insertText(`Получено ${new Date().toLocaleDateString()}`)"
      >
        Отметка
      </button>
      <button
        type="button"
        class="doc-tb-button"
        title="Найти выделенный текст"
        :disabled="!state.textSelected"
        @mousedown.prevent
        @click="lookUp(engine.getSelectedText())"
      >
        Найти
      </button>
    </template>
  </DocumentEditor>
</template>
```

- `@mousedown.prevent` сохраняет выделение в документе при нажатии кнопки — так же работают встроенные кнопки.
- Класс `doc-tb-button` придаёт кнопке вид собственных кнопок панели инструментов; подойдёт и любая другая разметка.
- Команды движка являются шагами отмены и обновляют `v-model` так же, как ввод текста. Поля `state` перечислены в разделе [EditorUiState](/docs/api#editoruistate).

## Печать и экспорт

Печать, скачивание PDF, экспорт в HTML и экспорт в Word также доступны в меню «Ещё» на панели инструментов; `Ctrl+P` запускает печать.

- **Печать** отрисовывает документ в скрытом фрейме с размером страницы и полями из параметров страницы, дожидается загрузки изображений и открывает диалог печати браузера. Чтобы получить PDF с выделяемым текстом, выберите там «Сохранить как PDF».
- **Скачивание PDF** (новое в 0.6.0) сразу сохраняет PDF, без диалога печати; его страницы — изображения, поэтому текст нельзя выделить. См. [Скачивание PDF](/docs/word-files#скачивание-pdf).
- **Экспорт в HTML** скачивает самостоятельную HTML-страницу со стилями документа и размером страницы.
- **Экспорт в Word** скачивает настоящий файл Word (`.docx`) с параметрами страницы, колонтитулами и разрывами страниц. Пункт «Открыть файл Word (.docx)» в том же меню загружает такой файл в редактор. См. [Файлы Word и большие документы](/docs/word-files).

Пропс `title` используется как заголовок при печати и как имя файла. Без него используется встроенная подпись `editor.document`. Символы, недопустимые в именах файлов, заменяются.

## Исходный HTML

Меню «Ещё» также переключает редактор в режим исходного HTML. Когда пользователь выходит из него, отредактированный HTML очищается и применяется к документу одним шагом отмены.

## Полноэкранный режим

Кнопка в строке состояния и меню «Ещё» включают и выключают полноэкранный режим; `Escape` выходит из него. Редактор занимает всю область просмотра, а прокрутка страницы блокируется. Внутри диалога (нативного элемента `dialog` или элемента с `role="dialog"`) редактор остаётся в пределах этого диалога, поэтому управление фокусом в диалоге продолжает работать. Порядок наложения задаётся переменной `--nuvra-fullscreen-z-index`, см. [Оформление](/docs/theming).

## Вставленное содержимое

Содержимое, вставленное из Word, Google Docs или с веб-страниц, очищается: неподдерживаемые элементы, атрибуты и небезопасные ссылки удаляются, остаётся только разметка, которую поддерживает редактор. Внутри блока кода вставляется только простой текст. Если вставить один веб-адрес поверх выделенного текста, выделение превратится в ссылку.
